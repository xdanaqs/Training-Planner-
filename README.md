# Training-Planner
Автор: Дарья Денисова  
Описание: «Training Planner» — GUI-приложение для планирования тренировок. Позволяет добавлять занятия, фильтровать их по параметрам (тип, дата и др.), сохранять данные в формате JSON и вести историю изменений через Git.
Инструкция:  
Добавление тренировок. Вводите данные (тип, дата, длительность и др.) и нажимаете «Добавить» — запись появляется в списке.  
Фильтрация записей. Выбираете критерии (тип тренировки, диапазон дат и т. д.), нажимаете «Применить фильтры» — видите только подходящие занятия.  
Сохранение данных. Все изменения автоматически записываются в файл trainings.json.  
Фиксация изменений в Git. После правки выполняете в терминале: git add trainings.json && git commit -m "Ваш комментарий" — сохраняете версию данных.  
Синхронизация с тренером/командой. Выполняете git push, чтобы отправить обновления в репозиторий; для получения чужих правок — git pull.  
Восстановление удалённых данных. Через историю коммитов находите нужную версию и выполняете git checkout [хеш_коммита] -- trainings.json — файл возвращается к прошлому состоянию.  
Перенос на другое устройство. Клонируете репозиторий: git clone [ссылка_на_репозиторий], запускаете приложение — данные из trainings.json загружаются в интерфейс.
